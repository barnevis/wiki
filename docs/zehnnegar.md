# ذهن‌نگار

**ساخت و مدیریت نقشه‌های ذهنی با مارک‌داون**

**ذهن‌نگار** یک اپلیکیشن وب اختصاصی برای **ساخت و مدیریت نقشه‌های ذهنی (Mind Maps)** است. این ابزار بر ادغام سادگی مارک‌داون با قدرت نمودارکشی تمرکز دارد و با همکاری هوش مصنوعی توسعه یافته است.

[گیت‌هاب](https://github.com/barnevis/zehnnegar) - [دمو](https://barnevis.github.io/zehnnegar)

### ویژگی‌های کاربردی
- **ویرایشگر زنده مارک‌داون:** امکان ویرایش محتوا به صورت زنده و مشاهده تغییرات نقشه ذهنی به صورت همزمان.
- **ذخیره‌سازی امن و محلی:** حفظ اطلاعات کاربر با ذخیره‌سازی محلی امن.
- **ورود و خروج با مارک‌داون:** امکان وارد کردن و خارج کردن داده‌ها با استفاده از فرمت مارک‌داون.
