# پارسی‌نگار

**ویرایشگر پیشرفته مارک‌داون فارسی**

**پارسی‌نگار** یک ویرایشگر مارک‌داون آنلاین و سبک است که به طور خاص برای نوشتن متن‌های فارسی و راست به چپ (RTL) طراحی شده است. این ویرایشگر پیشرفته با تمام امکانات، برای **تولید محتوای جدی، از مقالات تا مستندات فنی**، مناسب است.

[گیت‌هاب](https://github.com/barnevis/parsiNegar) - [دمو](https://barnevis.github.io/parsiNegar)

### ویژگی‌های کلیدی

- **پشتیبانی از چند مفسر:** از مفسرهای مختلفی چون **شه‌نشان**، **marked** و **پارس‌نشان** پشتیبانی می‌کند.
- **نمایش زنده:** امکان نوشتن، ویرایش و پیش‌نمایش متن‌های مارک‌داون را به صورت **همزمان** فراهم می‌کند.
- **خروجی متنوع:** امکان **خروجی گرفتن به فرمت‌های Markdown، HTML و PDF** را دارد.
- **نمودار و نقشه‌ذهنی:** قابلیت رسم نمودارها و دیاگرام‌های مختلف (Mermaid.js) و ایجاد **نقشه‌ذهنی** را دارد.
- **شخصی‌سازی:** پشتیبانی از تم‌های روشن، تاریک و سپیا، و قابلیت تغییر اندازه و نوع فونت.

### ساختار فنی

پارسی‌نگار بر اساس یک **معماری ماژولار و رویداد-محور (Event-Driven)** ساخته شده است. ماژول‌های اصلی آن شامل `app.js` (نقطه ورود)، `editor.js`، `eventBus.js` و `state.js` هستند. این پروژه از **جاوا اسکریپت خالص (Vanilla JS)** و **ماژول‌های ES6** استفاده می‌کند تا حجم نهایی آن به حداقل برسد.
