# شیرازه

**راهکار بدون سرور برای سندها و ویکی**

**شیرازه** یک راهکار مدرن و کاملاً سمت کاربر (Client-Side) است که برای ساخت **ویکی، مستندات و وب‌سایت‌های محتوا-محور** طراحی شده است. این پروژه نیازی به هیچ‌گونه فرآیند ساخت (Zero-Build) یا سرور پشتیبان ندارد.

[گیت‌هاب](https://github.com/barnevis/shirazeh) - [دمو](https://barnevis.github.io/shirazeh)

### معماری و عملکرد

- **بدون سرور:** تمام منطق برنامه، از مسیریابی گرفته تا رندر کردن مارک‌داون، در **مرورگر کاربر** اجرا می‌شود.
- **مبتنی بر مارک‌داون:** محتوای خود را با سینتکس ساده مارک‌داون بنویسید. ساختار فایل‌ها و پوشه‌ها کاملاً منعطف است.
- **پیکربندی محور:** رفتار اصلی برنامه از طریق یک فایل پیکربندی مرکزی (`config/config.js`) کنترل می‌شود و امکان شخصی‌سازی کامل رنگ‌ها، چیدمان و رفتار ویکی را می‌دهد.
- **سیستم افزونه (Plugins):** شیرازه از یک معماری ماژولار و **رویداد-محور** برای پشتیبانی از افزونه‌ها استفاده می‌کند. افزونه‌ها از طریق هوک‌های چرخه حیات (مانند `onInit` و `onPageLoad`) با هسته تعامل می‌کنند.
- **مفسر پیش‌فرض:** از مفسر **پارس‌نشان** استفاده می‌کند که قابلیت‌هایی مانند جعبه‌های هشدار، هایلایت متن و پشتیبانی از شعر را فراهم می‌کند.

### شخصی‌سازی

شما می‌توانید ظاهر ویکی را از طریق تنظیمات `theme` در `config.js` شخصی‌سازی کنید، که شامل انتخاب تم پیش‌فرض ('auto', 'light', 'dark') و بازنویسی متغیرهای رنگی CSS است.
